## 实现边界与尚未实机验证项

按用户要求停止下载端到端验证。自动补齐组件、官方包校验和重试代码保留，不能据此声称完整官方组件下载链路通过。此次更新使用已成功校验官方摘要的 mihomo 和现有已按本机清单校验的 OpenCode/Geo 数据，保留实际来源。

WebView2 在本机已安装；未执行“缺失运行时 → 下载完整安装程序 → 安装”的真实流程。当前进程未提升管理员权限，因此没有实际安装/移除防火墙规则，也没有触发 UAC 取消的交互验证。防火墙与严格启动检查默认关闭；规则范围解析和未启用状态已验证。

## 0.2.1 界面更新（2026-10-10）

- “重新检测连接”移至连接状态下方、节点名称左侧的可点击 WiFi 图标；从“更多”菜单移除。节点延迟独立显示，蓝色 ≤ 250 ms、琥珀色 251–800 ms、玫红色 > 800 ms；待检测灰色，节点探测失败 / 已停止时左下角显示红叉。
- 节点连通状态与后台服务状态分开传递；OpenCode 服务故障不会将仍可连通的节点标为断网。手动检测失败后，已运行服务继续每 60 秒探测，避免检测恢复被提前终止。
- 顶部整体采用浅色界面，将连接、网络出口和 Key 状态排为三个紧凑信息区。WiFi、节点和延迟集中在连接区的同一行，延迟使用柔和色标签；状态采用小圆点和淡色底。右上角五个按钮统一线条图标、圆角、间距，以及悬停、按下与键盘焦点状态。启动准备区同步采用简洁白色面板。
- “更多 → 帮助与使用指南”提供原生 WPF 离线页面，含项目介绍、三步开始、日常操作、延迟颜色与常见问题，支持章节导航、返回按钮和 Esc。
- 完整解决方案 Release 编译 0 警告、0 错误；单元测试 93/93。自包含发布程序 WPF 检查 30/30，覆盖图标入口、三档颜色、未检测 / 失败 / 检测中 / 恢复、后台故障区分、帮助导航与返回。WiFi 图形与右侧节点文字同高，保持紧凑间距和垂直居中。100%、150%、200% 渲染和 1020 × 500 最小内容区已查看。
- 自包含候选程序在隔离目录的真实 WebView2 / 服务生命周期检查通过：帮助页显示时后台服务存活；返回后页面 JavaScript 状态与本机认证保持；程序重启替换主进程、清理旧子进程、保留加密节点配置；退出后新子进程全部结束。
- 本次不进行组件下载测试、不调用真实 Claude 模型，也未人为断开本机物理网络。断网图标使用确定状态的 WPF 检查，周期检测与自动恢复沿用可控时钟验证；没有修改系统 DPI。

更新继续使用自包含 .NET 10 程序和原有运行组件，保留生产 data。编译所需临时 SDK、候选发布、隔离检查实例及各项目 bin/obj 在发布完成后清理。
