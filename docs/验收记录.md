- 单元测试 93/93；完整解决方案 Release 编译 0 警告、0 错误。
- 不下载组件的隔离冒烟测试 20/20：本地私有进程、配置与模型策略、拒绝无效 Key、代理退出提示及重启恢复、出口状态、进程清理。

## 实现边界与尚未实机验证项

按用户要求停止下载端到端验证。自动补齐组件、官方包校验和重试代码保留，不能据此声称完整官方组件下载链路通过。此次更新使用已成功校验官方摘要的 mihomo 和现有已按本机清单校验的 OpenCode/Geo 数据，保留实际来源。

WebView2 在本机已安装；未执行“缺失运行时 → 下载完整安装程序 → 安装”的真实流程。当前进程未提升管理员权限，因此没有实际安装/移除防火墙规则，也没有触发 UAC 取消的交互验证。防火墙与严格启动检查默认关闭；规则范围解析和未启用状态已验证。

本机没有启用其他客户端的 TUN；没有制造真实 TUN 冲突或执行 Windows 关机测试。关闭窗口选项采用 WPF 实际事件检查，缩放采用渲染检查，未改变系统 DPI。

早先停止下载时留有约 6.4 MB 的测试临时文件；用户明确要求清理后，该文件随隔离测试目录一并删除。

发布入口为 app/EasyClaude.exe；app 包含 coreclr.dll、hostfxr.dll 与 PresentationFramework.dll，未捆绑固定版 WebView2。发布时原数据保留，未复制生产凭据到隔离测试目录。

2026-10-09 后续按用户要求完成本地清理，删除约 2.790 GiB：所有项目 bin/obj 构建输出、.tools 中的临时 SDK/历史发布/隔离实例、OpenCode 凭据与会话数据库、WebView2 缓存、日志、临时文件和可重建的 mihomo 工作数据。当前 app、运行组件 bin、data/settings.json 与加密节点配置保留；旧 Key 和会话已从本项目运行目录移除。下一次使用需要重新填写 Key；下次源码编译需要 .NET 10 SDK。

源码仓库为 https://github.com/wenquantongxin/EasyClaude，创建时确认 visibility=PRIVATE。运行目录、真实节点、凭据、数据库和编译输出均不进入 Git。README 和 tools/clean-local.ps1 记录了可重复的项目清理步骤。
